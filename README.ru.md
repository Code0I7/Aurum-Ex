## Что это

**Ex — от Extended.** Форк вырос из настоящей задачи: заменить четырёхлетнюю таблицу в Google Sheets так, чтобы ни одна цифра из неё не потерялась, а вопросы, на которые таблица не отвечала, наконец получили ответ.

У таких таблиц набирается один и тот же набор стен. Один уровень подкатегорий — «Продукты → Молочное → Сыр» невозможны. Нет позиций в чеке — покупка это одно число, и истории цены на конкретный товар просто не существует. Нельзя отличить перевод от знакомого от собственного заработка. Начальный остаток счёта приходится проводить доходом, потому что положить его больше некуда.

Aurum-Ex — это то, во что эти стены превратились:

| Стена | Чем заменена |
|---|---|
| Один уровень подкатегорий | Вложенность любой глубины, в операции выбирается любой уровень |
| Покупка — одно число | Позиции в чеке с количеством, единицей и ценой за единицу |
| Нет истории товара | Справочники товаров и магазинов, кривая цены по каждому — в пересчёте на базовую единицу |
| Переводы считаются доходом | Расчёты с людьми: долги и займы различаются, и ни то, ни другое не заработок |
| Одна валюта | Мультивалютность с курсами ЦБ на дату операции |
| Начальный остаток как доход | Настоящий начальный остаток у счёта |
| Все в одной колонке | Участники — на кого пришёлся доход или расход, включая питомцев |
| HTTP Basic Auth | Настоящий вход с серверной сессией |

## Возможности

### Приход и расход

- **Операции** с типом, категорией, участником, метками и заметками; делятся на несколько категорий, когда в одном чеке лежит разное.
- **Период** — месяц, год или всё время. Выписка по счёту за один август ни о чём не говорит: путаницу между парой связанных счетов видно только на всей истории.
- **Выписка по счёту** показывает обе стороны перевода, а баланс считается для выбранного счёта.
- **Склейка повторов** — четыре поездки на автобусе за день сворачиваются в строку «Автобус ×4».
- **Разделители дней** с итогами, чтобы список читался как банковская выписка.
- **Счета** с группировкой по банкам, условиями кредита, льготными периодами и рассрочками.
- **Стоимость в рабочих часах** — во что покупка обошлась рабочим временем, по ставке того года, когда она случилась.

### Анализ

- **Обзор** — реальный доход, расход, итог, норма сбережений, заработок за час, траты по категориям, крупнейшие расходы, движение по месяцам — и по дням, когда выбран месяц.
- **Движение денег** — доход против расхода за любой период, с учётом начального остатка.
- **Отчёты** — траты по категориям во времени; открываются на самой крупной статье, а не на первой по алфавиту.
- **Капитал** — активы минус обязательства во времени. Никогда не рисуется раньше первой записи: ровная линия по нулю — это утверждение, которого данные не подтверждают. У каждого актива своя история цены, поэтому подорожавшая квартира и подешевевшая машина видны кривыми, а не одним числом.
- **Советы** — наблюдения по вашим же цифрам, а не общие рекомендации.

### Планы

- **Бюджеты** — потолок на месяц, который предупреждает при переходе.
- **Планирование** — разовые, ежемесячные и ежедневные планы, развёрнутые на год вперёд. Ежедневные умеют считаться по отработанным дням вместо календарных, поэтому февраль пересчитывается сам.
- **Отслеживание** — те несколько категорий, за которыми следите сейчас: помесячно и рядом с итогом прошлого года.
- **Цели** со взносами, привязанные к настоящему счёту.
- **Регулярные платежи** с расписанием проведения.
- **Долги и расчёты** — кто кому должен, полностью вне доходов. Считать ли данное в долг тратой — настройка, а не решение автора: деньги со счёта ушли, и они вернутся, и оба ответа честные.

### Инвестиции

- **Портфель** с учётом лотов по FIFO: первым списывается самый старый, потому что средняя цена молча занижает убыток.
- **Криптовалюта** с живыми ценами через CoinGecko (хватает бесплатного ключа) и разбивкой по портфелям.
- **Калькулятор доходности** — сложный процент, пополнения, прогноз.

### Справочники и данные

- **Категории** любой вложенности, с цветом и значком, применяемыми ко всей ветке по запросу.
- **Товары, магазины и единицы** с приведением к базовой мере: «1,5 л за 120 ₽» и «500 мл за 55 ₽» наконец сравнимы.
- **Импорт таблицы** — перенос учёта из Google Sheets с предпросмотром до записи и автоматической раскладкой плоского списка категорий по веткам. См. [docs/spreadsheet-import.md](docs/spreadsheet-import.md).
- **Импорт CSV** банковских выписок.
- **Полная резервная копия** по всем таблицам, с тестом, который пересчитывает каждую строку до выгрузки и после восстановления.

### Само приложение

- **Три оформления** — «Золотое» (обсидиан и золото, мрамор в светлом), «Современное» (тот же акцент, больше воздуха и движения) и «Классическое» (вид оригинального Aurum). У каждого светлая и тёмная пара. См. [docs/brand.md](docs/brand.md).
- **Два языка** — русский и английский везде.
- **Сначала телефон** — работает каждый экран, включая широкие таблицы.
- **Кружки с пояснением** — «!» рядом с названием раздела объясняет, зачем он и что показывает.
- **Настоящий вход** — страница входа, серверная сессия, защита от перебора, аварийный ключ.
- **REST API** на всё, что умеет интерфейс — см. [DOCS.md](DOCS.md).

## Запуск

Три контейнера — Postgres, бэкенд на FastAPI и фронтенд под nginx, — связанные Docker Compose. Больше ничего ставить не нужно.

```bash
git clone https://github.com/Code0I7/Aurum-Ex.git
cd Aurum-Ex
cp .env.example .env
```

Перед первым запуском поменяйте в `.env` два значения:

| Переменная | Зачем |
|---|---|
| `AURUM_POSTGRES_PASSWORD` | Пароль к собственному Postgres приложения. В шаблоне намеренно стоит `change-me`. |
| `AURUM_RECOVERY_KEY` | Аварийный ключ для сброса забытого пароля (`openssl rand -base64 48`). Пусто — сброс выключен целиком. |

`AURUM_ADMIN_PASSWORD` лучше оставить пустым: приложение при первом открытии само попросит задать пароль в браузере, и он вообще не окажется в файле на диске.

```bash
docker compose up -d --build
```

Открыть **http://localhost:3000**. Миграции применяются сами; счёт по умолчанию и стандартные категории заводятся автоматически.

```bash
docker compose down          # остановить, данные сохранить
docker compose up -d         # запустить снова
docker compose down -v       # остановить И удалить данные навсегда
git pull && docker compose up -d --build   # обновиться
```

Данные лежат в томе докера (`aurum_pgdata`), а не в папке репозитория: они переживают пересборку и `git pull`. Перед любым рискованным шагом выгрузите копию из раздела **Настройки → Резервная копия**.

### Публикация наружу с TLS

Необязательный сервис `edge` — это nginx перед приложением с сертификатом Let's Encrypt и калиткой по секретной ссылке: первый заход с ключом кладёт куку на год, всё остальное получает молчаливый обрыв соединения. По умолчанию слушает нестандартный порт: 443 на машине, где живёт что-то ещё, обычно уже занят, а браузер на порт в адресе не ругается, если сертификат настоящий.

Включается строкой `COMPOSE_PROFILES=public` в `.env` вместе с `AURUM_DOMAIN`, `AURUM_PUBLIC_PORT` и `AURUM_GATE_KEY`. Без них `docker compose up -d` поднимает те же три контейнера, что и раньше.

Нужен обычный адрес без порта — поставьте `AURUM_PUBLIC_PORT=443`, и только его: остальное не меняется. Порт должен быть свободен, иначе контейнер не поднимется, — на машине, где уже стоит свой nginx или другая панель, 443 обычно занят ими.

## Безопасность

В отличие от оригинала, у Aurum-Ex есть собственный вход:

- **Страница входа и серверная сессия.** Пароль хранится хешем (scrypt), сессия — в HttpOnly-куке, которую не прочитать скриптом со страницы. «Выйти» действительно обрывает сессию на сервере.
- **Одна учётная запись на всё домохозяйство.** Это не многопользовательский режим: все входят под одним администратором и видят одни данные, а различаются участником в операции. Так семейный бюджет и устроен.
- **Забытый пароль** сбрасывается ключом `AURUM_RECOVERY_KEY`, который знает только владелец сервера. Обычная смена пароля требует текущего, чтобы никто из домашних не заперся снаружи по случайности.
- **Защита от перебора** — после `AURUM_MAX_FAILED_LOGINS` неудач вход блокируется на `AURUM_LOCKOUT_MINUTES` минут.
- **`AURUM_SECURE_COOKIES=true`** при публикации. Для `localhost` браузеры делают исключение, поэтому SSH-туннель продолжает работать.
