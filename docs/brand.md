# Знак и значок: какие файлы и откуда берутся

Фирменные файлы лежат в `frontend/public/brand/` и подменяются целиком:
положили новый файл под тем же именем, пересобрали фронтенд — всё.
Никакого кода при этом трогать не нужно.

## Что где лежит

| Файл | Что это | Где показывается |
|---|---|---|
| `plate-dark.png` | Широкая плашка, обсидиан | Меню и экран входа в тёмной теме |
| `plate-marble.png` | Она же, мрамор | То же в светлой теме |
| `icon-dark.png` | Квадратный знак, обсидиан | Свёрнутое меню, заставка загрузки |
| `icon-marble.png` | Он же, мрамор | То же в светлой теме |
| `favicon-32.png`, `favicon-192.png` | Значок вкладки | Вкладка браузера |
| `apple-touch-icon.png` | Значок для домашнего экрана | iOS |

## Как выбирается вариант

Тёмный или мраморный решает разметка, а не CSS: растровую картинку
значением переменной не перекрасишь. Выбор делает `useIsDark()` в
`components/layout/Logo.tsx`.

Можно было бы показывать обе картинки и прятать одну через `display`, но
тогда браузер грузил бы оба файла — лишние сотни килобайт на каждом заходе
ради того, чего никто не увидит.

Мраморный вариант считается «светлым» для **всех** оформлений, включая
классическое: белых плашек пока нет, и мрамор на светлом полотне выглядит
уместнее обсидиана.

## Размеры

**Плашка.** Высота задаётся разметкой, ширина считается сама — жёсткого
соотношения нет, так что новый файл может быть любой близкой формы.
Показывается высотой **34** в меню и **44** на экране входа. Нынешние
файлы — примерно 3,6 : 1 (876 × 244). Разумный предел ширины: в
развёрнутом меню под неё отведено 192 точки, то есть при высоте 34 плашка
не должна быть шире, чем 5,6 : 1.

**Квадратный знак.** Показывается **30** (свёрнутое меню) и **44**
(заставка). Нынешние файлы 270 × 270.

**Значки вкладки.** 32, 192 и 512 точек, плюс 180 для iOS. Все делаются из
`icon-dark.png` скриптом — руками их готовить не нужно, см. ниже.

Формат везде PNG с прозрачным фоном: исходники растровые, и обводить их в
вектор значило бы рисовать заново — знак перестал бы совпадать сам с собой.

## Если пришли новые исходники

Скрипт обрезает прозрачные поля (внутри файла они только уменьшают знак —
отступы задаёт разметка), приводит значок к квадрату и раскладывает
размеры значка вкладки:

```bash
python scripts/build_brand_assets.py <папка-с-исходниками>
```

Ожидаемые имена в папке: `Aurum-Ex-dark.png`, `Aurum-Ex-marble.png`,
`A-Ex-icon-dark.png`, `A-Ex-icon-marble.png`.

Значок для iOS кладётся на сплошную подложку с полями: прозрачность там
превращается в чёрный квадрат, а система накладывает собственное
скругление — своё внутри системного выглядит рамкой в рамке.
